<h1 align="center">Task Manager</h1>

<p align="center">
  A simple Task Manager application built with Python.
</p>

<h2>✨ Features</h2>

<ul>
  <li>➕ Add new tasks</li>
  <li>📋 View all tasks</li>
  <li>✏️ Update existing tasks</li>
  <li>🗑️ Delete tasks</li>
  <li>✅ Mark tasks as completed</li>
  <li>💾 Save and load tasks using JSON</li>
</ul>

<h2>🛠️ Technologies Used</h2>

<ul>
  <li>🐍 Python</li>
  <li>📄 JSON</li>
</ul>

<h2>🚀 How to Run</h2>

<ol>
  <li>Make sure Python is installed.</li>
  <li>Run the <code>main.py</code> file.</li>
  <li>Use the menu to manage your tasks.</li>
</ol>

<h2>💾 Data Storage</h2>

<p>
  Tasks are stored in the <code>tasks.json</code> file, so the data remains
  saved even after closing the program.
</p>
