Task Manager

A simple Task Manager application built with Python.

Features

* Add new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Save and load tasks using JSON

Technologies Used

* Python
* JSON

How to Run

1. Make sure Python is installed.
2. Run the main.py file.
3. Use the menu to manage your tasks.

Data Storage

Tasks are stored in the tasks.json file, so the data remains saved even after closing the program.
